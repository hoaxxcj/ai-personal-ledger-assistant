# 设置页面完整需求

## 整体说明
设置页面为产品的辅助功能页，所有功能均为纯前端实现，无需后端支持。**绝对不包含任何 DeepSeek API 密钥相关的输入、配置或展示功能**，API 密钥由开发团队统一在代码中配置，用户完全无感知。页面整体风格与首页保持一致，使用 Element Plus 组件，布局简洁清晰。

---

## 一、数据管理模块（核心刚需，必做）

1. **模块标题**为「数据管理」，使用 Element Plus 卡片组件包裹。
2. 包含两个功能按钮，横向排列，按钮宽度一致：
   - **「导出所有账单」按钮**：点击后将 `localStorage` 中存储的所有账单数据转换为 CSV 文件并自动下载。  
     CSV 文件包含字段：`ID`、`类型（收入 / 支出）`、`类别`、`金额`、`日期`、`备注`；  
     文件命名格式：`个人账单_YYYY-MM-DD.csv`（`YYYY-MM-DD` 为当前日期）。
   - **「清空所有数据」按钮**：按钮颜色为红色，点击后弹出 Element Plus 确认对话框，提示文字为：  
     > ⚠️ 此操作将永久删除所有账单数据，无法恢复，确定继续吗？  
     包含「取消」和「确认删除」两个按钮。  
     用户点击「确认删除」后，清空 `localStorage` 中的 `finance_records` 数组，自动刷新页面并返回首页，同时弹出成功提示「所有数据已清空」。
3. 两个按钮下方添加一行灰色小字提示：  
   > 所有数据仅存储在您的本地浏览器中，导出和清空操作均不会上传任何数据至服务器。

---

## 二、基础偏好设置模块（体验增强，必做）

1. **模块标题**为「基础偏好」，使用 Element Plus 卡片组件包裹。
2. 包含三个可配置项，垂直排列，每个配置项左侧为文字说明，右侧为操作控件：
   - **「默认显示月份」**：下拉选择框，选项为「当前月份」和「上月」，默认选中「当前月份」。  
     用户选择后，下次打开应用时自动切换到对应月份的账单页面，配置保存到 `localStorage` 中。
   - **「金额显示千分位」**：开关组件，默认开启。  
     开启后，所有金额数字（统计卡片、账单列表、图表）均显示千分位分隔符（如 `¥1,234.56`）；关闭后显示原始数字（如 `¥1234.56`）。配置保存到 `localStorage` 中。
   - **「记账后自动关闭弹窗」**：开关组件，默认开启。  
     开启后，点击记账表单的「保存」按钮并提交成功后，自动关闭记账弹窗；关闭后，提交成功后弹窗不关闭，方便连续记账。配置保存到 `localStorage` 中。
3. 所有配置项修改后**立即生效**，无需额外点击保存按钮。

## 三、关于我们模块（产品完整性，必做）

1. **模块标题**为「关于我们」，使用 Element Plus 卡片组件包裹。
2. 包含以下内容，垂直居中排列：
   - **产品名称**：AI 个人记账与消费分析助手，字体加粗，字号稍大。
   - **版本号**：V1.0
   - **产品介绍**：一款结合 AI 智能分析的个人记账工具，所有账单数据本地存储，保护您的隐私安全。
   - **技术栈**：Vue 3 + Vite + Element Plus + ECharts + DeepSeek AI
   - **AI 模型声明**：AI 分析功能由 DeepSeek 大模型提供支持，分析结果仅供参考，不构成专业财务建议。
   - **项目归属**：AI 编程实训营 Module 1 实践项目
3. 所有文字内容左对齐，行高适中，整体排版美观。

---

## 四、页面交互与通用要求

1. 页面路由为 `/settings`，点击左侧导航栏的「设置」图标和文字即可进入。
2. 进入页面时，自动从 `localStorage` 中读取已保存的配置项，初始化所有控件的状态。
3. 所有按钮点击时添加加载状态，操作完成后弹出对应的成功或失败提示（使用 Element Plus 的 `Message` 组件）。
4. 页面适配桌面端浏览器，在不同分辨率下布局不错乱。
5. 无数据时不影响页面显示，导出功能在无账单数据时点击，弹出提示「暂无账单数据可导出」。
